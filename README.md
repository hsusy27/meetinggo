# 會議記錄自動整理工具

讀取會議錄音檔，自動產出**逐字稿**、**會議記錄**與**待辦事項**。

## 功能

- 支援 mp3、m4a、wav 等格式，自動切成每 30 分鐘一段處理，避免長會議一次送出失敗
- 會議記錄採「主題／單位 → 重點 → 細節」的巢狀條列，主管指示會標示「（重要指示）」
- 待辦事項列出負責人、具體任務、期限；逐字稿沒提到的一律寫「未提及」，不自行編造
- Gemini 伺服器忙碌或網路中斷時自動重試，並依序改用備用模型，避免長時間等待後整個失敗
- 逐字稿已產生過的話會直接重用，不用每次都重新轉錄

## 環境需求

- Python 3.10 以上
- [ffmpeg](https://ffmpeg.org/)（Windows：`winget install Gyan.FFmpeg --source winget`，安裝後需重開終端機）
- [Gemini API 金鑰](https://aistudio.google.com/)

## 安裝與使用

**1. 下載專案**

```bash
git clone https://github.com/hsusy27/meetinggo.git
cd meetinggo
```

**2. 安裝套件**

```bash
pip install google-genai python-dotenv httpx
```

**3. 設定金鑰**

在資料夾裡新增一個 `.env` 檔案，內容： GEMINI_API_KEY=你的金鑰 


**4. 放入錄音檔**

把錄音檔放進資料夾，並在 `main.py` 最上方的設定區修改檔名：

```python
AUDIO_FILE = "test.m4a"      # 改成你的檔名
```

**5. 執行**

```bash
python main.py
```

**6. 查看結果**

結果會存在 `output/` 資料夾：

| 檔案 | 內容 |
|---|---|
| `逐字稿.txt` | 完整逐字稿 |
| `會議記錄.md` | 會議概要、決議事項、待辦事項 |

想重新產生逐字稿時，先刪除 `output/逐字稿.txt` 再執行。

### 可調整的設定（在 `main.py` 最上方）

| 設定 | 說明 |
|---|---|
| `AUDIO_FILE` | 要處理的錄音檔 |
| `CHUNK_MINUTES` | 每幾分鐘切一段（預設 30） |
| `MEETING_TITLE` | 會議標題；留空由 AI 依內容擬定 |

## 設計說明

- **為什麼要切段？** 長會議一次送出，容易因為逾時或輸出長度上限而失敗。切成 30 分鐘一段，任何一段出問題都不會拖垮整個流程。
- **為什麼用 ffmpeg 而不是 pydub？** pydub 依賴 Python 3.13 已移除的 `audioop` 模組，在較新的 Python 上容易出錯；直接呼叫 ffmpeg 更穩定，也能處理各種音訊格式。
- **為什麼要自動換模型？** 新推出的模型常因需求量大而暫時無法使用（503），依序嘗試備用模型可以避免整個流程因此卡住。

## 已知限制

- 逐字稿目前沒有說話者標記，待辦事項的「負責人」只能依對話內容判斷。
- 語音辨識可能有同音錯字，重要的決議與待辦請對照錄音確認。
- 切段處是硬切，句子可能被切在兩段之間。
- 需要網路，錄音內容會上傳到 Google Gemini API 處理。上班使用前請先確認公司的資安規範是否允許，並留意 [Gemini API 服務條款](https://ai.google.dev/gemini-api/terms)中免費與付費額度在資料使用上的差異。
